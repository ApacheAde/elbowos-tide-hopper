# Tide Hopper

Full-colour Python 3 neon frogger / tide-hop arcade for [ElbowOS](https://x.com/ElbowOS).

Hop a lime neon frog across vertical lanes of glowing traffic. Reach the cyan goal strip for points. Magenta / cyan / gold vehicles will knock you back.

## Play

```bash
pip install -r requirements.txt
python3 tide_hopper.py --play
```

Controls: ← → sidestep, ↑ / Space hop up, ↓ hop down, R restart.

## Record a 9:16 reel

```bash
python3 tide_hopper.py --record
```

Outputs a 1080×1920 15-second H.264 MP4 with title, score, and x.com/ElbowOS overlay.
